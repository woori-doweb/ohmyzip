# ohMypic 도움말

ohMypic은 Windows에서 이미지를 탐색하고 보고 편집하는 프로그램입니다. 창 하나에 두 가지 모드가 있습니다.

- **목록보기**: 왼쪽에 폴더 트리, 가운데에 폴더의 이미지, 오른쪽에 미리보기 창과 카메라 정보 창(선택)이 있습니다.
- **크게보기**: 이미지 하나가 창을 채웁니다. Esc를 누르면 목록보기로 돌아갑니다.

## 목록보기

- 폴더 트리에서 폴더를 고르거나, 주소 표시줄에 경로를 입력하고 Enter를 누르거나, **파일 > 폴더 열기**(Ctrl+Shift+O)를 사용합니다.
- **보기** 메뉴에서 보기 형식(썸네일, 큰 아이콘, 아이콘, 목록, 자세히, 필름스트립)과 정렬(이름, 종류, 크기, 날짜, 오름차순/내림차순)을 고릅니다.
- **보기 > 미리보기 창**, **보기 > 카메라 정보 창**은 선택한 이미지와 카메라 정보를 보여 줍니다.
- 이미지를 두 번 클릭하거나 Enter를 누르면 크게보기로 엽니다.
- 폴더를 창에 끌어 놓으면 그 폴더를 열고, 이미지 파일을 끌어 놓으면 크게보기로 엽니다.

## 크게보기

- 다음/이전 이미지: 오른쪽/왼쪽 화살표, Page Down/Page Up, Space, 마우스 휠. 처음/마지막: Home/End.
- 확대/축소: + 와 -, 또는 Ctrl + 마우스 휠. 0은 실제 크기(이미지 픽셀 하나 = 화면 픽셀 하나), * 는 창에 맞추기입니다.
- 큰 이미지는 끌어서 움직입니다. 구석의 내비게이터가 보이는 부분을 표시합니다.
- 전체 화면: F11 또는 Enter, 또는 이미지 두 번 클릭. Esc는 먼저 전체 화면을 끝내고, 다시 누르면 목록보기로 돌아갑니다.
- 보기 회전: Ctrl+](오른쪽), Ctrl+[(왼쪽). 다른 이미지로 넘어가거나 창을 닫을 때 회전을 저장할지 묻습니다(환경설정에서 자동 저장으로 바꿀 수 있습니다). JPEG 파일은 크기가 맞으면 화질 손실 없이 회전합니다.

## 연속보기

F5를 누릅니다. 왼쪽/오른쪽 화살표로 넘기고, Space로 일시 정지/계속, Esc로 끝냅니다. 오른쪽 클릭하면 연속보기 메뉴가 나옵니다. 이미지당 시간과 페이드 효과는 **도구 > 환경설정 > 연속보기**에 있습니다.

## 편집

**이미지** 메뉴(크게보기 도구 모음의 **편집** 단추)는 보고 있는 이미지나 선택한 이미지에 적용됩니다.

| 명령 | 단축키 |
|---|---|
| 회전하기… | Ctrl+T |
| 크기변경… | Ctrl+R |
| 포맷변환… | Ctrl+E |
| 일괄편집…(크기변경, 회전, 이름 바꾸기, 포맷변환을 한 번에) | Ctrl+M |

결과는 상태 표시줄에 나옵니다. 실패한 파일이 있을 때만 알림 창이 뜹니다.

## 파일

| 명령 | 단축키 |
|---|---|
| 파일 열기… | Ctrl+O |
| 다른 이름으로 저장… | Ctrl+S |
| 인쇄하기… | Ctrl+P |
| 파일 속성 | Alt+Enter |
| 파일 복사/잘라내기/붙여넣기 | Ctrl+C / Ctrl+X / Ctrl+V |
| 이미지 복사(그림을 클립보드로) | Ctrl+Shift+C |
| 삭제 | Del |
| 이름 바꾸기… | F2 |
| 모두 선택 | Ctrl+A |
| 상위 폴더 | Alt+위쪽 화살표 또는 Backspace |
| 새로 고침 | Ctrl+F5 |

삭제한 파일은 휴지통으로 이동합니다(환경설정에서 바꿀 수 있습니다).

## 환경설정

**도구 > 환경설정**(F4)에는 일반(삭제, 숨김 파일, 회전 저장, JPEG 품질, 언어), 보기(맞춤 방식, 마우스 휠, 이어서 넘기기, 배경, 내비게이터), 연속보기, 썸네일, 파일 연결, 탐색기 메뉴(아래 참고) 페이지가 있습니다. 설정은 `%APPDATA%\ohMypic\settings.json`에, 창 크기와 창 배치는 같은 폴더의 `window.json`에 저장됩니다.

"(준비 중)"으로 표시된 항목은 이후 버전에서 제공합니다.

## 파일 연결과 탐색기 메뉴

둘 다 지금 Windows 사용자 계정에만 적용되고(관리자 권한 불필요) 바로 반영됩니다. 환경설정의 확인·취소로 되돌리지 않습니다.

- **도구 > 파일 연결…**: 이미지 형식을 체크하고 **등록**을 누르면 그 형식의 '연결 프로그램'과 Windows 설정 > 앱 > 기본 앱에 ohMypic이 나타납니다. Windows는 프로그램이 스스로 기본 앱이 되는 것을 허용하지 않으므로 **Windows 기본 앱 열기**를 눌러 거기서 ohMypic을 고르세요. **등록 해제**는 ohMypic이 추가한 항목만 지우며, 형식마다 지금 쓰는 기본 앱은 바꾸지 않습니다.
- **도구 > 탐색기 메뉴…**: **등록…**을 누르면 기록할 레지스트리 위치와 프로그램 경로를 먼저 보여 주고, 이미지 파일의 오른쪽 클릭 메뉴에 **ohMypic** 하위 메뉴(열기, 연속보기, 회전하기…, 크기변경…, 포맷변환…, 일괄편집…)를 추가합니다. Windows 11에서는 "추가 옵션 표시"(Shift+F10) 아래에 나옵니다. 메뉴 문구는 등록할 때의 화면 언어로 기록됩니다. **등록 해제**로 메뉴를 지웁니다.

명령줄(창 없음, 종료 코드 0 = 성공, 1 = 실패):

| 옵션 | 동작 |
|---|---|
| `--register-associations` / `--unregister-associations` | 파일 연결 등록 / 해제 |
| `--register-shell-menu` / `--unregister-shell-menu` | 탐색기 메뉴 등록 / 해제 |

메뉴 항목은 다음 옵션 뒤에 파일 경로를 붙여 ohMypic을 실행합니다. `--slideshow`(파일이 있는 폴더를 그 파일부터 연속보기), `--rotate`, `--resize`, `--convert`, `--batch`(해당 편집 대화상자만 띄우고, 닫으면 ohMypic도 끝납니다).

## 업데이트

**업데이트 자동 확인**이 켜져 있으면(**도구 > 환경설정 > 일반**, 기본값 켬) ohMypic이 하루에 한 번까지 GitHub에서 새 릴리스를 확인하고, 백그라운드에서 내려받아 SHA-256 체크섬을 검증한 뒤 ohMypic을 닫을 때 설치합니다. **도움말 > 업데이트 확인…**은 현재 버전과 새 버전, 릴리스 노트를 보여 주고, **업데이트 후 다시 시작**을 누르면 바로 설치한 뒤 보던 이미지나 폴더를 다시 엽니다. ohMypic 폴더의 파일만 바뀌고 설정은 그대로 남습니다.

## 지원 형식

BMP, GIF, JPEG, PNG, TIFF, ICO, JPEG XR, DDS와 Windows에 설치된 이미지 디코더가 지원하는 형식을 엽니다. BMP, GIF, JPEG, PNG, TIFF로 저장합니다.
