# ohmyZip 도움말

ohmyZip 은 Windows 용 압축 관리자입니다. 압축 파일을 열어 내용을 보고, 풀고, 테스트하고, 새로 만들거나 항목을 고칠 수 있습니다.

## 설치·실행 조건

- Windows 10 또는 11 (x64)
- .NET Desktop Runtime 9 — 없으면 Microsoft 공식 사이트에서 ".NET Desktop Runtime 9" 를 설치하세요.
- 설치 폴더의 `ohmyZip.exe` 를 실행합니다. 압축 파일 경로를 첫 번째 인자로 주면 그 파일을 바로 엽니다.
- 설정 파일: `%APPDATA%\ohmyZip\settings.json` (환경 변수 `OHMYZIP_DATA_DIR` 를 정하면 그 폴더). 암호는 저장하지 않습니다.

## 기능

- **열기**: Ctrl+O, 창으로 끌어 놓기, 명령줄 인자. 형식은 파일 내용(앞 바이트)으로 판별합니다.
- **암호 걸린 압축 파일**: 열기·테스트·풀기·추가 중 암호가 필요하면 암호 창이 뜹니다. 틀리면 "암호가 올바르지 않습니다" 라고 알리고 다시 묻습니다. 암호는 열린 압축 파일에 대해서만 메모리에 둡니다.
- **목록**: 왼쪽 폴더 트리(F7), 오른쪽 파일 목록. 머리글을 누르면 정렬(폴더 먼저, 오름/내림차순 표시), 머리글 오른쪽 클릭으로 칼럼 설정.
- **보기 방식**: 보기 > 파일 목록 > 자세히 / 간단히 / 아이콘 / 큰 아이콘.
- **칼럼**: 압축 크기, 원본 크기, 파일 종류, 수정한 날짜, 압축 방식, 암호 방식, CRC, 속성, 파일 설명, 부가 정보. 엔진이 값을 주지 않는 칼럼(속성·파일 설명·부가 정보)은 비어 있습니다.
- **찾기**: Ctrl+F 로 검색 칸에 이동. 압축 파일 전체(모든 폴더)에서 이름을 찾고 결과에 전체 경로를 보여 줍니다. `*` `?` 와일드카드를 쓸 수 있고, `/` 를 넣으면 경로 전체와 비교합니다. Enter = 그 항목이 있는 폴더로 이동해 선택, Esc = 지우기.
- **풀기**: Ctrl+E 로 풀기 창. 풀 위치(찾아보기, 새 폴더 만들기), 대상(전체 / 선택한 항목), 같은 이름이 있을 때(묻기 / 덮어쓰기 / 건너뛰기 / 이름 바꾸기), 풀고 나서 폴더 열기.
- **알아서 풀기**: 파일 메뉴 또는 툴바 풀기 옆 단추. 최상위 항목이 하나면 압축 파일이 있는 폴더에 바로, 여러 개면 압축 파일 이름으로 된 폴더(이미 있으면 "이름 (2)")에 풉니다.
- **안전한 풀기**: 대상 폴더 밖을 가리키는 경로·링크 항목은 거부하고, 전체 8GB·항목 200,000개 한도를 넘으면 멈춥니다. 취소하면 이번 작업에서 만든 파일을 지우고 덮어쓰던 파일은 되돌립니다.
- **새로 압축**: Ctrl+N → 파일 선택 → 새 압축 창. 폴더 추가, 저장 경로, 형식(ZIP·7Z·TAR·TAR.GZ·GZ), 압축 레벨(0 저장 … 9 최고), 암호(AES-256)·파일 이름 암호화(7Z), 분할 크기. 형식이 지원하지 않는 옵션은 꺼져 있고 이유가 함께 표시됩니다. 성공하면 새 압축 파일을 엽니다. 실패·취소하면 만들던 파일을 남기지 않습니다.
- **항목 고치기**: 파일 추가(Ins), 삭제(Del), 이름 바꾸기(F2). 고치는 동안 임시 파일에 쓰고 성공해야만 바꾸므로 실패·취소하면 압축 파일은 그대로입니다.
- **클립보드**: Ctrl+C = 선택 항목을 임시 폴더에 풀어 파일로 복사(탐색기에 붙여 넣기), Ctrl+V = 클립보드의 파일을 현재 폴더에 추가, '파일의 경로명을 클립보드로 복사' = `압축 파일 경로\항목 경로` 줄 목록. 임시 폴더는 창을 닫을 때 지웁니다.
- **압축 파일 설명**: F8 로 설명 창 표시, Ctrl+Shift+M 으로 편집(형식이 설명을 지원할 때만).
- **진행 창**: 처리량/전체, 백분율, 속도, 남은 시간. 전체 크기를 모르면 "진행률을 알 수 없음". 취소 단추나 Esc 로 취소합니다.
- **파일 작업**: 다른 이름으로 저장(같은 경로는 거부), 압축 파일 삭제(Ctrl+Del, 휴지통으로), 압축 파일이 있는 폴더 열기, 새 창 띄우기.
- **환경 설정(F5)**: 일반(시작 화면, 테마, 동작 줄이기, 자동 업데이트), 파일 연결, 압축 풀기(기본 위치·충돌 정책·폴더 열기), 압축하기(기본 형식·레벨), 보기/편집(삭제 전 확인, 목록 방식, 칼럼). 확인 = 저장·적용, 취소 = 바꾸지 않음, 초기화 = 모든 설정을 기본값으로.
- **파일 연결(기본 프로그램)**: 환경 설정 > 파일 연결 > 'ohmyZip 을 기본 프로그램으로 등록…' → 무엇을 기록하는지 확인하고 '등록' → 열리는 Windows 기본 앱 설정에서 ohmyZip 을 고르면 기본 프로그램이 됩니다. Windows 는 프로그램이 기본 프로그램을 직접 바꾸지 못하게 하므로 마지막 선택은 사용자가 합니다. 대상 확장자는 .zip .7z .rar .tar .gz .tgz 이고, 현재 사용자 범위(HKCU)에만 기록하므로 관리자 권한이 필요 없으며, 확장자의 지금 기본 프로그램 설정은 바꾸지 않습니다. 되돌리려면 같은 페이지의 '등록 해제'. 이 페이지의 단추는 확인·취소와 관계없이 바로 적용됩니다. 프로그램 폴더를 옮겼다면 다시 등록하세요. 명령줄: `ohmyZip.exe --register-file-types` / `ohmyZip.exe --unregister-file-types` (창 없이 실행, 성공 0·실패 1 로 끝남).
- **보기**: 툴바 크게 / 작게 / 구식(글자만) / 숨기기, 툴바 버튼 설정, 상태 표시줄, 시작 화면(F6), 항상 위에 표시, 색상 설정(앱 안의 라이트/다크).

## 업데이트

새 버전은 GitHub 저장소(`woori-doweb/ohmyzip`)의 릴리스에서 받습니다. 내려받은 압축 파일은 함께 올라온 SHA-256 값과 대조해 맞을 때만 설치합니다.

- **자동 확인**: ohmyZip 창이 뜨면 하루에 한 번 새 버전이 있는지 확인하고, 있으면 뒤에서 조용히 내려받습니다. 다 받으면 상태 표시줄에 "새 버전 … 을(를) 받았습니다" 라고 알립니다. 인터넷에 연결되지 않았거나 확인에 실패하면 아무것도 표시하지 않고 다음에 다시 확인합니다.
- **닫을 때 설치**: 받아 둔 새 버전은 ohmyZip 을 닫을 때 설치 폴더에 넣습니다. 다음에 실행하면 새 버전이 시작됩니다. 설치가 끝까지 되지 않으면 설치 폴더를 원래대로 되돌리고, 다음 실행에서 다시 받습니다. 바꾼 파일의 옛 본(`*.ohmyzip-old`)은 다음 실행 때 지웁니다.
- **지금 업데이트**: 도움말 > 업데이트 확인…. 최신 버전이면 상태 표시줄에 알리고, 새 버전이 있으면 현재·새 버전과 바뀐 점(커밋 기록)을 보여 줍니다. '업데이트' 를 누르면 진행 창에서 내려받고(취소 가능) 설치한 뒤 같은 압축 파일 인자로 다시 시작합니다.
- **끄기**: 환경 설정(F5) > 일반 설정 > '새 버전을 자동으로 받고 프로그램을 닫을 때 설치' 를 끕니다. 끄면 자동으로 확인·설치하지 않고, 도움말 > 업데이트 확인… 으로만 업데이트합니다.
- **설치 폴더에 쓸 수 없을 때**: Program Files 처럼 쓰기 권한이 없는 폴더에 설치했다면 업데이트할 수 없다고 알립니다. ohmyZip 을 관리자 권한으로 실행해 다시 업데이트하거나, 사용자 폴더로 옮겨 설치하세요.
- 작업 파일은 `%LOCALAPPDATA%\ohmyZip\updates` 에 둡니다. 현재 버전은 도움말 > 정보(F1)에서 볼 수 있습니다.

## 준비 중·지원하지 않는 기능

메뉴에 "(준비 중)" 으로 표시되고 누를 수 없습니다.

- 압축 파일 완전 삭제, 압축 파일 악성코드 검사
- 새 창 띄우기(관리자 권한)
- 제품 등록 / 제품 등록 삭제
- 암호 관리자 (암호 창의 '암호 관리자에서 선택' 도 준비 중)
- 이미지 파일 미리 보기
- 손상된 압축 파일 복구, 압축 파일 암호 복구
- 토론 게시판 열기, 홈페이지 열기
- 환경 설정의 탐색기 메뉴(시스템 등록은 사용자 동의 후 — 준비 중), 보안·고급 설정
- 언어: 한국어만 지원합니다.
- 형식별 기능(만들기·암호·분할·설명·수정)은 엔진이 지원하는 만큼만 켜집니다. 지원하지 않으면 메뉴·단추가 꺼지고 이유가 툴팁에 나옵니다.
